# Матрица прослеживаемости

Связывает требования с решениями, проверками и кодом.
Обновляется **в том же запросе на слияние**, в котором меняется требование,
решение или тест. Полнота матрицы проверяется на защите (ЛР 9Б).

**Состояния**: `Записано` → `Спроектировано` → `Реализовано` → `Проверено`

## Критерии приёмки, не покрытые проверками (пока)

| Критерий | Требование | Когда появится проверка |
|---|---|---|

## Обратная проверка: шаг пути пользователя без требования

| Шаг пути (из Карты пути) | Из какого требования следует |
|---|---|
| Нашёл точку, выбрал слот | `FR-02` |
| Забронировал и оплатил | `FR-03`, `FR-04` |
| **Получил подтверждение (зал, время, контакты)** | **Требования не было** → добавлено `FR-07` |
| **Владелец видит, кто пришёл (встреча на месте)** | **Требования не было** → добавлено `FR-13` (возможность снять/отметить) |
| Отменил бронь | `FR-05` (для музыканта) |
